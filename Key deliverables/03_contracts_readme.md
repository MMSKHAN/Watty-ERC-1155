# ⚡ WTY Energy Settlement System

A blockchain-based **energy reporting and settlement platform** built with **Solidity, Hardhat, and React**.

This project demonstrates how energy production data from registered meters can be securely recorded and converted into **tokenized energy credits** using Ethereum smart contracts.

The system records:

- Energy meter registration
- Energy production reports
- Energy credit minting
- Credit burning
- Final settlement events

The goal is to create a **transparent and auditable energy settlement mechanism** using blockchain technology.

# System Roles

## Admin

Responsible for system configuration.

Permissions:

- Register meters
- Assign or remove minters

---

## Minter

Authorized backend/oracle system that can:

- Report energy production
- Mint energy credits
- Finalize settlement events

---

## User

Regular users who can:

- Hold energy credits
- Burn credits when redeemed

---

# Contract Functions

## setMinter

Assign or remove a minter.

```solidity
setMinter(address account, bool value)
Only callable by Admin.
```
## registerMeter

Registers a new energy meter.
```
registerMeter(bytes32 meterId, address owner, bytes32 metadataHash)
```
| Parameter    | Description                       |
| ------------ | --------------------------------- |
| meterId      | Unique identifier of the meter    |
| owner        | Owner wallet address              |
| metadataHash | Hash reference for meter metadata |

## reportEnergy

Reports energy production from a meter.
```
reportEnergy(bytes32 meterId, bytes32 intervalId, uint256 whDelta, bytes32 dataHash)
```
| Parameter  | Description            |
| ---------- | ---------------------- |
| meterId    | Registered meter ID    |
| intervalId | Time interval ID       |
| whDelta    | Energy produced (Wh)   |
| dataHash   | Hash of off-chain data |

### mintCredits

Mint ERC1155 energy credits.
```
mintCredits(bytes32 meterId, address to, uint256 tokenId, uint256 amount, bytes32 ref)
```
Credits represent verified energy production.
## burnCredits

Burn energy credits when redeemed.
```
burnCredits(address from, uint256 tokenId, uint256 amount, bytes32 ref)
```
Callable by:

- Token owner

- Authorized minter

## finalizeSettlement

Records final settlement data.
```
finalizeSettlement( bytes32 siteId, bytes32 period, uint256 totalWh, uint256 totalTokens, bytes32 proofHash )
```
## Events

The contract emits the following events:
```
MeterRegistered
EnergyReported
CreditsMinted
CreditsBurned
SettlementFinalized
```
These events provide full transparency and auditability.

# Hardhat Setup

Navigate to Hardhat directory:
```
cd Hardhat
```
## Install dependencies:
```
npm install
```
## Compile Smart Contracts
```
npx hardhat compile
```
Artifacts are automatically exported to the UI project:
```
paths: {
  artifacts: "../UI/src/artifacts"
}
```
This allows the frontend to directly use the contract ABI.
## Start Local Blockchain node
```
npx hardhat node
```
Local RPC:

```
http://127.0.0.1:8545
```

Chain ID:

``` 
31337
 ```

 ### Deploy Contract

```
npx hardhat run scripts/deploy.js --network localhost
```
